Деньги и прибыль обновляются автоматически по выданным заказам. Закупочные партии считаются оплаченными, включая товар в пути. Комиссия, налог и доставка рассчитываются по тарифам CRM. Это расчётный остаток, а не банковская выписка: внешние расходы, пополнения и вывод денег учитывайте через сверку остатка. Без начального остатка расчёт начинается с 0 ₸ по всей истории. Доступная прибыль уже входит в деньги. При отсутствующей себестоимости прибыль не подтверждена. Старые ручные снимки используют приблизительную историческую базу; одна сверка фиксирует точную базу для дальнейшего автоматического расчёта.
